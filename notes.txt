Building a subtitle-focused platform for movie lovers is a high-value project—especially tackling native-sounding localized translations, which traditional translators like Google Translate often fail at due to missing context and regional idioms.

---

## 1. System Architecture & Tech Stack

Based on your familiarity with modern web development, here is the optimal stack setup:

* **Framework:** Next.js (App Router, Server Actions, Route Handlers)
* **UI & Styling:** Tailwind CSS + `shadcn/ui` (Components like Dialog, DropdownMenu, Progress, Accordion, Sheet)
* **Database & ORM:** MongoDB with Mongoose *or* PostgreSQL with Prisma.
* *Recommendation:* **PostgreSQL + Prisma** is ideal for structured data like user accounts, download counts, and subtitle metadata relationships.


* **File Storage:** Cloudflare R2 or AWS S3 (SRT/VTT files are small, but direct file serving requires fast S3-compatible storage).
* **AI Engine:** OpenAI `gpt-4o-mini` or Claude 3.5 Haiku via Vercel AI SDK (fast and cost-effective for line-by-line subtitle translation with contextual system prompts).
* **Subtitle Processing:** Custom Node.js parsing utilities (`srt-parser-2` or `subtitles-parser`) for parsing, timestamp offsetting, and re-assembling SRT/VTT structures.

## 2. Core Features Breakdown

### Feature 1: Subtitle Downloader

* **Third-Party Integration:** Integrate OpenSubtitles REST API v3 or Subscene scraping/API.
* **Functionality:** Search movies/TV shows by title or IMDB ID, filter by language and format, and stream direct file downloads to the user.

### Feature 2: Context-Aware Native AI Translator

* **The Challenge:** Literal translations break idioms, movie slang, and natural cadence.
* **The AI Prompt Strategy:** Process subtitle blocks in batches (e.g., 50–100 lines at a time) passing preceding lines as context.
* **System Prompt Focus:**
> "Translate the following subtitle lines into natural, conversational native Bangla. Do not translate literally. Preserve tone, humor, regional idioms, and keep sentence lengths short enough to fit video subtitle timing standards."



### Feature 3: Two-File Subtitle Timestamp Sync Fixer

* **How It Works:**
1. User uploads **File A** (Correct timing, wrong language/bad translation).
2. User uploads **File B** (Perfect translation, broken timing).
3. The tool parses timestamps from File A, maps the text lines from File B onto File A's exact timecodes line-by-line (or via anchor-point linear interpolation), and exports a synchronized file.

## 3. MVP Scope & Phased Architecture

To launch quickly without getting stuck in complexity, limit the MVP to these exact deliverables:

### Phase 1: MVP (Launchable Core)

1. **User Auth:** NextAuth.js (Auth.js v5) or Clerk.
2. **Sync Fixer Tool (Client-Side & Fast):**
* Drag-and-drop dual SRT upload UI using `shadcn/ui`.
* Client-side preview showing mapped timestamps alongside translated lines.
* One-click SRT/VTT download.


3. **AI Translation Module:**
* Single file upload -> Choose Target Language -> AI Batch Stream Processing -> Download.
* Free tier usage limit per user (e.g., 3 translations/day to control API costs).


4. **Basic Search & Download:** OpenSubtitles API integration for direct search and download.

### Phase 2: Post-MVP Enhancements

* Subtitle editor with interactive video player preview (`video.js` with custom tracks).
* Community subtitle sharing & rating system.
* Webhook notifications when a requested subtitle translation finishes processing.

  id           String        @id @default(cuid())

## 5. Subtitle Sync Logic (2-File Alignment)

Below is the foundational logic for mapping localized text from File B onto the precise timestamps of File A:

```typescript
import parser from 'subtitles-parser';

interface SubtitleLine {
  id: string;
  startTime: string;
  endTime: string;
  text: string;
}

export function syncSubtitles(fileAText: string, fileBText: string): string {
  // File A contains correct timestamps
  const parsedA: SubtitleLine[] = parser.fromSrt(fileAText, true);
  // File B contains desired localized text
  const parsedB: SubtitleLine[] = parser.fromSrt(fileBText, true);

  // Map text from B onto timing of A
  const synced = parsedA.map((lineA, index) => {
    const lineB = parsedB[index];
    return {
      id: String(index + 1),
      startTime: lineA.startTime,
      endTime: lineA.endTime,
      text: lineB ? lineB.text : lineA.text, // Fallback if line counts mismatch
    };
  });

  return parser.toSrt(synced);
}

```
